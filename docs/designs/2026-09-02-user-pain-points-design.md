# 方寸数学 · 用户群体视角改进设计

## Intent Contract

```
intent: 从学生、家长、教师三大用户群体的真实使用痛点出发，补齐当前「方寸数学」在学习激励、数据安全、错题闭环、家长/教师可见性四方面的短板，让产品从「能用的单机题库」升级为「学生愿持续用、家长能监督、教师能布置」的学习工具。
constraints:
  - 不破坏现有 133 技巧/100 随机引擎的题库结构
  - 离线可用为底线（WebView 壳 + assets 本地资源）
  - localStorage 持久化为兼容层，云同步为增量
  - 不引入需 ICP 备案/账号体系的服务端（沙箱无后端能力）
success_criteria:
  - 学生侧：连续学习有可视化激励（打卡日历/连胜火苗）
  - 学生侧：错题自动沉淀到「错题本」并支持按学段/技巧筛选重练
  - 数据侧：进度可一键导出为 JSON 文件（本地下载），家长/教师可查看
  - 数据侧：「重置进度」改为两步确认 + 二次确认弹窗，误删可恢复
  - 教师侧：每个技巧可一键复制「技巧卡片 + 随机 8 题」为纯文本，便于粘贴到微信/钉钉布置
risk_level: medium
```

## Verification Contract

```
verify_steps:
  - run tests: node audit_qgen.js（确保题库数学严谨性未受影响）
  - check: 启动本地服务器，依次访问 #/path、#/review、#/progress、#/about，确认新功能渲染
  - check: 模拟做错一题 → 进度页与「错题本」标签均出现该题
  - check: 进度页点击「导出进度」→ 浏览器下载 math-mastery-export.json
  - check: 进度页点击「重置进度」→ 出现二次确认弹窗
  - confirm: 浏览器 console 无 JS 报错；APK 重新构建后安装无签名冲突
```

## Governance Contract

```
approval_gates:
  - P0 改进完成后的截图验收（用户确认）
  - APK 重新构建后的安装测试
rollback: 通过 git 回退 app.js/styles.css/data.js 到改动前版本；assets/www 同步覆盖即可
ownership: 开发者本人
```

## Scope

| 范围内（In）               | 范围外（Out）       |
| --------------------- | -------------- |
| 学习打卡日历 + 连胜火苗激励       | 账号注册/登录体系（无后端） |
| 错题本：自动沉淀 + 按学段/技巧筛选重练 | 云端同步服务（需后端）    |
| 进度导出 JSON 文件（本地下载）    | 多设备实时同步        |
| 重置进度二次确认 + 导入恢复       | 家长端独立 APP      |
| 学习统计：累计答题数/正确率/连续学习天数 | 教师布置作业后台       |
| 通关测试难度分级（基础/进阶混合比例可调） | AI 自适应出题算法     |
| 收藏夹：题目一键收藏 + 收藏夹集中复习  | 题目社区分享         |
| 学习页添加「上一技巧/下一技巧」快速跳转  | 学习社区/论坛        |
| 解锁规则可切换「顺序解锁/自由探索」模式  | 付费内容解锁         |

## Decisions

| # | 决策     | 选择                                | 否决的替代方案                   |
| - | ------ | --------------------------------- | ------------------------- |
| 1 | 数据持久化  | localStorage 为主 + 导出/导入 JSON 文件   | 需后端的云同步（沙箱无后端）            |
| 2 | 错题本存储  | 复用现有 weak 结构，新增 reviewList 视图聚合展示 | 新建独立错题数组（重复存储）            |
| 3 | 打卡激励   | 日期戳数组 + 简单火苗 SVG                  | 复杂成就系统（YAGNI）             |
| 4 | 难度分级   | 在 qgen 调用处加 levelMix 参数           | 重写所有生成器                   |
| 5 | 收藏夹    | 新增 starred 字段 + 收藏夹路由             | 浏览器书签（跨设备不可用）             |
| 6 | 重置保护   | 二次确认弹窗 + 导出提醒                     | 撤销按钮（localStorage 已删无法撤销） |
| 7 | 技巧快速跳转 | 学习页顶部添加「← 上一技巧」「下一技巧 →」           | 面包屑导航（移动端空间不足）            |
| 8 | 解锁模式   | 设置项可切换，默认顺序解锁                     | 强制自由探索（破坏循序渐进）            |

## Surface

**localStorage 结构（state 对象扩展）**：新增 `starred`（收藏题 id 数组）、`dailyLog`（打卡日期戳数组）、`stats`（累计答题数/正确数/总用时秒）。现有 `weak` 结构不变，错题本通过遍历 weak 聚合呈现。

**新增路由**：`#/favorites`（收藏夹复习页）。现有路由 `#/path`、`#/review`、`#/progress`、`#/about` 不变。

**UI 变更**：进度页新增「导出进度」「导入进度」按钮与二次确认弹窗；学习页顶部新增上一/下一技巧跳转条；底部标签栏「复习」页拆分为「错题本」（薄弱点）+「收藏夹」两个子 tab；关于页新增学习统计卡片。

**文件改动**：app.js（核心逻辑扩展）、styles.css（新增错题本/收藏夹/打卡日历/导出弹窗样式）、index.html（底部标签栏微调）。

## Risks & Open Questions

1. **localStorage 容量限制（5-10MB）**：133 技巧 × 8 题 + 错题/收藏记录可能接近上限。风险中等——需在导出时压缩，并提示用户定期清理已掌握技巧的错题记录。
2. **导出 JSON 的隐私**：含学习行为数据，需在关于页说明数据本地存储、不上传。
3. **难度分级与现有 qgen 接口兼容**：部分生成器已内部分级，新增 levelMix 可能产生题量不足。先用启发式：基础题占 60%、进阶 40%，不足时降级为基础。
4. **解锁模式切换的 UX**：从顺序解锁切到自由探索后，已掌握的技巧保持掌握状态，但学生可能跳过基础直接学高阶导致挫败。需在切换时提示风险。
5. **无后端的局限**：家长/教师无法远程查看进度，只能靠学生主动导出分享。这是当前架构的硬约束，未来如需云同步需引入轻量后端（如 Supabase）。
